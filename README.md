Le **jeu du Labyrinthe** est une application Java basée sur l’exploration et la réflexion.  
Le joueur incarne un personnage placé à l’entrée d’un labyrinthe généré aléatoirement.  
Son objectif est simple : **trouver la sortie** sans se faire piéger par les murs.

---

## 🎮 Modes de jeu

### 🔓 Mode libre
Le joueur choisit :
- la **taille du labyrinthe** (largeur et hauteur),
- le **pourcentage de murs** à générer.  
  Ce mode permet d’expérimenter librement différents niveaux de difficulté.

### 🧩 Mode progression
Le joueur avance à travers plusieurs **étapes**, chacune composée de **trois défis** :
- **Facile**
- **Moyen**
- **Difficile**

Chaque **défi** propose un labyrinthe avec un taux de murs plus élevé.  

Les **deux premières étapes** sont différentes par la taille des labyrinthes.  
Et la **troisième étape** propose une vue différente du labyrinthe.  

Une fois la sortie atteinte, le joueur **valide le défi** et peut passer à l’étape suivante.
